# 🏗 Jh-service-app

Мобильное приложение для учёта данных по погрузчикам: ввод, хранение, поиск и фильтрация записей. Реализована функция распознавания текста (OCR) для быстрого заполнения полей из фото документов/накладных. Проект демонстрирует работу с локальной БД, DI и адаптивным UI под рабочие сценарии.

## 📱 Функционал

- **Учёт данных по погрузчику:** ввод и сохранение ключевых параметров (номер погрузчика, тип работ, время, объём, водитель и т.д.)
- **Поиск и фильтрация:** быстрый поиск по номеру, дате, водителю; фильтрация по статусу/типу работ
- **Распознавание текста (OCR):** загрузка фото документа/накладной → автоматическое извлечение текста → предзаполнение полей формы
- **Локальное хранение:** все записи сохраняются в локальной базе данных (Room) — приложение работает без интернета
- **Просмотр истории:** список записей с пагинацией, сортировкой и детализацией по каждой записи
- **Обработка состояний:** корректное отображение пустых списков, ошибок OCR, отсутствия данных

## 🛠 Технологии и стек

- **Язык:** Kotlin (JVM target 1.8)
- **UI:** XML + ViewBinding
- **DI:** Dagger (без Hilt)
- **Асинхронность:** Kotlin Coroutines + Lifecycle-aware компоненты (ViewModel/LiveData)
- **База данных:** Room (локальное хранение записей, миграции, DAO)
- **Навигация:** Navigation Component (фрагменты)
- **Список:** RecyclerView (адаптеры, DiffUtil — если используется)
- **Сборка:** Gradle Kotlin DSL
- **Версии SDK:**
  - `minSdk`: 24
  - `targetSdk`: 34
  - `compileSdk`: 34

📋 Установка и запуск
  1. Склонируй репозиторий: bash
     - git clone https://github.com/PavelVolniy/Jh-service-app.git
     - cd Jh-service-app
  2. Открой проект в Android Studio.
  3. Собери и запусти:
     - В Android Studio: выбери устройство/эмулятор и нажми Run.
     - Через терминал: ./gradlew assembleDebug
🔑 Особенности реализации
   - OCR: логика распознавания вынесена в отдельный слой (Repository), результат возвращается через Flow/LiveData в ViewModel. Обработка ошибок: «не удалось распознать», «текст не найден» и т.п.
   - Room: сущности, DAO и миграции настроены для хранения записей по погрузчикам. Поддержка сортировки и фильтрации на уровне запросов (SQL/Room Query).
   - Валидация: проверка обязательных полей, форматов (например, номера погрузчика), ограничений длины текста.
   - UX: состояния загрузки, пустой список («нет записей»), ошибки сети/OCR отображаются явно и понятно.

🧪 Тесты

На текущий момент тесты отсутствуют. Для будущего расширения планируются:
   - Unit-тесты для DAO, репозиториев и валидаторов
   - Instrumentation-тесты для форм ввода и навигации между фрагментами
   - Тесты сценариев OCR: корректность извлечения текста, обработка пустых/неудачных изображений
